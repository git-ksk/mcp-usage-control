# Code of Conduct

[English](CODE_OF_CONDUCT.md) | [日本語](CODE_OF_CONDUCT.ja.md)

## Commitment

`mcp-usage-control` を、建設的で技術的に厳密かつ参加しやすいopen-source projectにすることを目指します。

idea、code、test、documentation、incidentについて敬意を持って議論してください。技術的な意見の相違は通常のことですが、personal attack、harassment、intimidation、discrimination、意図的な妨害は認めません。

## Expected behavior

- 人ではなくimplementationやassumptionを批評する。
- correctness、safety、reproducibility、trade-offを具体的に説明する。
- good faithを前提にしつつ、security / accounting-sensitive claimには根拠を求める。
- experience level、language、background、communication styleの違いを尊重する。
- private vulnerability reportやconfidential informationを公開しない。
- Issue、PR、log、exampleへsecret、personal data、production identifierを載せない。

## Unacceptable behavior

harassment、差別的・侮辱的な発言、脅迫、望まれない性的言動、doxxing、private vulnerability detailの意図的公開、継続的なtrollingなど、参加をunsafe / hostileにする行為を含みます。

## Scope

repository Issue、Pull Request、review、このprojectに関係するdiscussion、およびprojectが管理するcommunity spaceに適用します。

## Enforcement

maintainerは、このpolicyに反するcontributionをedit、hide、lock、removeし、community保護のため必要な場合は参加を制限できます。

conduct report自体にsecurity vulnerability、credential、その他sensitive technical detailが含まれる場合は、public投稿せず [SECURITY.ja.md](SECURITY.ja.md) のprivate reporting pathを利用してください。

通常のconduct concernは、利用可能なprivate GitHub channelなど適切な非公開手段でrepository maintainerへ連絡してください。incident理解に必要な情報だけを含めてください。

enforcement decisionはtechnical conclusionへの賛否ではなく、behaviorとproject safetyに基づいて行います。
